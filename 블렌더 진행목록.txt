현재 프로젝트는 Unity 기반의 멀티플레이 게임이며, 쿠키들이 플레이어이고 한 명의 술래가 괴물인 비대칭 술래잡기 게임이다. Blender MCP를 사용하여 기존 씬의 레이아웃을 유지하면서 게임에 어울리는 3D 오브젝트와 애니메이션을 제작해줘.

1. 공통 아트 스타일
전체적인 분위기: 귀엽고 아기자기한 3D 카툰 스타일의 다크 판타지
주제: 쿠키와 괴물이 등장하는 마법의 숲
형태: 둥글고 단순한 실루엣, 과장된 비율, 읽기 쉬운 형태
재질: 부드러운 저광택 재질과 약간의 광택이 있는 마법 효과
색상: 짙은 보라색, 청록색, 어두운 회색, 따뜻한 주황색과 쿠키의 황금빛 갈색
모델링: 게임 내에서 멀리서도 식별할 수 있도록 과도하게 작은 장식과 복잡한 디테일을 피할 것
텍스처: 가능하면 저용량 텍스처와 단순한 재질을 사용하고, Unity에서 색상과 재질을 조정하기 쉽게 구성할 것

2. 과자 집 모델

과자집을 만들건데, 그 과자집은 앞,뒤,옆,앞 으로 과자 문이 있어야하고, 
snackshop.png를 참고하여 오브젝트를 만들어줘. 크기는 30 * 30 * 30 정도로 잡을거야
2-1. 작업 목표

Blender MCP를 이용해 Unity 게임 TagOfChaos에 사용할 수 있는 고품질 3D 과자집 모델을 제작해줘.

첨부한 과자집 콘셉트 이미지를 주요 시각적 참고 자료로 사용해줘. 전체적으로 귀엽고 아기자기한 과자집이지만, 마녀의 저주가 깃든 듯한 불길한 분위기를 표현해줘.

이 모델은 게임 내에서 플레이어가 접근할 수 있는 건물이며, 정면, 후면, 좌측면, 우측면에 각각 하나씩 총 4개의 문이 있어야 해. 네 개의 문은 모두 실제로 열릴 수 있는 구조로 제작해줘.

모델을 만들기 전에 현재 Unity 프로젝트의 캐릭터 크기와 기존 씬의 배치 정보를 확인하고, 이를 기준으로 집의 크기를 정해줘.

2-2. 건물의 전체 디자인
기본 형태
동화 속 진저브레드 하우스를 기반으로 한 둥글고 아기자기한 형태
지붕은 두꺼운 초콜릿 과자와 녹아내린 보라색 설탕 아이싱으로 구성
벽은 구운 쿠키와 진저브레드로 구성
건물 모서리에는 사탕 기둥과 초콜릿 장식을 배치
지붕 꼭대기에는 작은 해골 장식과 보라색 보석을 배치
굴뚝은 초콜릿 벽돌로 만들고 보라색 연기가 나오는 형태
건물 전체에 쿠키 조각, 젤리, 사탕, 설탕 장식을 적절히 배치
분위기와 색상
벽: 따뜻한 황금빛 갈색과 진한 구운 쿠키색
지붕: 짙은 초콜릿 갈색
아이싱: 옅은 보라색과 분홍빛 보라색
문: 진한 갈색의 초콜릿 나무 질감
창문: 따뜻한 주황색 빛과 신비로운 보라색 빛
장식: 붉은색, 분홍색, 청록색 사탕과 보라색 마법 보석

귀여운 느낌을 유지하되, 해골 장식, 빛나는 보라색 눈 모양의 창문, 마법 룬, 굴뚝의 보라색 연기 등으로 불길한 느낌을 더해줘.

2-3. 반드시 지켜야 할 4개의 문 구조

건물은 정사각형에 가까운 형태로 제작하고, 각 면의 중앙에 문 하나씩 배치해줘.

문 배치는 다음과 같아.

Front: 정면 중앙에 출입문 1개
Back: 후면 중앙에 출입문 1개
Left: 좌측면 중앙에 출입문 1개
Right: 우측면 중앙에 출입문 1개

각 문의 크기는 게임 속 쿠키 캐릭터가 무리 없이 통과할 수 있도록 설정해줘. 캐릭터의 실제 크기를 확인할 수 없다면 임시 기준 크기를 정하고, 추후 Unity에서 조정할 수 있도록 문틀과 문을 별도 오브젝트로 제작해줘.

각 문의 세부 구조:

두꺼운 초콜릿 문틀
진저브레드로 된 문짝
문 중앙에 소용돌이 모양의 마법 문양
둥근 사탕 손잡이
문 위쪽에 작은 해골 장식
문 양옆에는 사탕 기둥과 작은 보라색 마법석
문 주변에는 녹아내리는 아이싱 장식

문은 네 면 모두 독립적으로 배치하고, 한 면의 문을 열어도 다른 문이나 벽의 메시와 충돌하지 않도록 해줘.

중요: 네 개의 문은 단순한 장식이 아니라 Unity에서 별도로 조작할 수 있어야 해. 문틀과 문짝을 분리하고, 각 문짝의 회전축은 경첩 위치에 설정해줘.

문 이름은 다음과 같이 지정해줘.

Door_Front
Door_Back
Door_Left
Door_Right

각 문틀은 다음 이름으로 설정해줘.

DoorFrame_Front
DoorFrame_Back
DoorFrame_Left
DoorFrame_Right

문짝의 회전축은 실제 경첩이 달리는 가장자리로 지정해줘. Unity에서 회전 애니메이션을 적용했을 때 문짝이 문틀을 뚫고 회전하거나 문이 벽과 간섭하지 않도록 확인해줘.

2-4. 지붕과 굴뚝

지붕은 집의 전체적인 실루엣을 결정하는 주요 요소야.

양쪽으로 경사진 두꺼운 과자 지붕
지붕 표면에 초콜릿 타일을 겹쳐 배치
지붕 가장자리에 보라색 아이싱이 흘러내리는 모양
아이싱 끝부분에는 둥근 설탕 장식과 작은 사탕을 배치
지붕 중앙에는 작은 해골 장식과 마법 보석을 배치
굴뚝은 건물의 뒤쪽 또는 측면에 배치
굴뚝 윗부분에서는 보라색 마법 연기가 나오는 것처럼 표현

지붕은 각 면의 문을 가리지 않도록 충분한 높이와 돌출 길이를 확보해줘. 특히 좌우 문 위에 처마가 너무 낮게 내려와 출입을 방해하지 않도록 해줘.

2-5. 창문과 마법 장식

각 면에는 문과 조화를 이루는 창문을 배치해줘.

문 양옆이나 문 위쪽에 둥근 창문을 배치
창틀은 두꺼운 쿠키로 제작
창문 내부에는 주황색이나 보라색으로 빛나는 유리
일부 창문은 해골 모양 또는 괴물의 눈 모양으로 제작
창문 주변에는 작은 사탕과 아이싱 장식 배치

마법 장식은 건물의 모든 면에 균등하게 분산해줘. 한쪽 면만 지나치게 화려하거나 반대쪽 면이 밋밋하지 않도록 해줘.

2-6. 건물의 내부

집 안쪽은 게임에서 플레이어가 이동하거나 문을 통과하는 상황을 고려해서 제작해줘.

내부 공간은 쿠키 캐릭터가 이동할 수 있을 정도로 넓게 확보
바닥은 진저브레드 또는 초콜릿 재질
천장은 지붕과 연결되지만 내부에서 플레이어의 시야를 가리지 않도록 구성
문 네 개는 서로 통하는 출입구로 구성
벽과 바닥은 게임에서 사용할 수 있도록 단순한 충돌 구조를 별도로 제공
필요하다면 내부 장식으로 마법 책장, 작은 사탕 선반, 마법 룬 등을 배치

내부 장식은 캐릭터 이동을 방해하지 않는 수준으로 제한해줘. 게임에서 실제로 들어가지 않는 건물이라면 내부는 간단한 구조로 제작하고, 나중에 확장할 수 있도록 해줘.

2-7. 모델링 방식과 최적화

이 모델은 Unity 실시간 게임에 사용될 예정이므로 게임용 에셋 제작 기준을 지켜줘.

Unity 기준 1유닛을 1미터로 설정
모든 메시의 이름은 영어와 언더스코어로 구성
모델링 후 불필요한 버텍스와 중복 메시를 정리
곡면은 적절한 폴리곤 수를 사용해 부드럽게 표현
작은 장식은 메시를 과도하게 세분화하지 말 것
서로 다른 재질을 사용하는 부분은 머티리얼별로 구분
가능하면 장식물은 반복 사용이 가능하도록 별도의 오브젝트로 분리
바닥, 벽, 지붕, 문, 문틀, 굴뚝을 독립적인 메시로 구성
문짝의 피벗과 회전 방향을 확인
오브젝트의 원점은 Unity에서 쉽게 배치할 수 있도록 설정
불필요한 투명 재질은 사용하지 말 것

건물의 외부 장식용 메시와 게임플레이에 필요한 충돌 메시를 분리해줘.

충돌 메시에는 복잡한 장식과 작은 사탕 등을 포함하지 말고, 벽과 바닥, 문틀의 주요 형태만 단순한 충돌체로 구성해줘.

2-8. 재질과 텍스처

모든 재질은 Unity에서 조정하기 쉽게 구성해줘.

구운 쿠키 재질: 황금빛 갈색, 미세한 표면 요철
초콜릿 재질: 진한 갈색, 부드러운 광택
아이싱 재질: 밝은 보라색, 약간의 광택
사탕 재질: 반투명하거나 광택이 있는 다채로운 색상
마법 보석: 발광 효과를 Unity에서 추가할 수 있도록 별도의 재질로 분리
창문 유리: Unity에서 빛을 표현할 수 있도록 독립된 재질로 분리

텍스처를 사용하는 경우 UV가 겹치지 않도록 정리하고, Unity에서 텍스처를 교체하거나 수정할 수 있도록 관련 파일을 함께 저장해줘.

2-9. Unity용 애니메이션 준비

문을 열고 닫는 애니메이션을 Unity에서 만들 수 있도록 준비해줘.

각 문짝은 경첩을 기준으로 회전할 수 있어야 하며, 문을 여는 방향은 집 내부 또는 외부 중 한 방향으로 통일해줘.

문짝에 별도의 애니메이션을 적용할 경우에는 다음 클립을 제작해줘.

Door_Front_Open
Door_Front_Close
Door_Back_Open
Door_Back_Close
Door_Left_Open
Door_Left_Close
Door_Right_Open
Door_Right_Close

각 애니메이션은 짧고 자연스러운 회전 동작으로 구성해줘. 다만 애니메이션이 Unity에서 개별적으로 제어될 수 있도록 오브젝트 계층과 애니메이션 클립을 분리해줘.

2-10. 최종 검수

모델링이 완료되면 Blender에서 다음 뷰를 각각 확인하고, 문제가 있으면 수정해줘.

정면 뷰: 정면 문과 지붕, 창문 및 장식 확인
후면 뷰: 후면 문이 정확히 중앙에 배치되어 있는지 확인
좌측면 뷰: 좌측 문과 문틀의 형태 확인
우측면 뷰: 우측 문과 문틀의 형태 확인
탑 뷰: 네 개의 문이 서로 다른 방향에 배치되어 있는지 확인
원근 뷰: 집 전체의 비율과 귀엽지만 불길한 분위기 확인
내부 뷰: 플레이어가 네 개의 문 사이로 이동할 수 있는 공간이 확보되어 있는지 확인

최종적으로 각 방향의 스크린샷을 렌더링하여 확인할 수 있도록 해줘.

작업 도중 중요한 구조를 임의로 변경하거나 메시를 합쳐 문을 개별적으로 제어할 수 없게 만들지 말 것. 문제가 생기면 현재 작업 상태와 해결 방법을 먼저 설명해줘.

솥단지 밑에는 숯불로 불과 연기가 모락모락 나야돼 그리고

1. 작업 전 프로젝트 분석

모델링을 시작하기 전에 현재 Unity 프로젝트를 분석한다.

확인할 사항:

기존 Unity 프로젝트의 폴더 구조
현재 사용 중인 캐릭터 모델과 캐릭터 크기
플레이어 이동 속도와 충돌체 크기
게임 카메라의 시점과 높이
기존에 제작된 과자집과 마녀의 솥단지 모델
기존 프로젝트의 조명과 렌더링 방식
기존 환경 모델의 폴리곤 수와 텍스처 해상도

기존 프로젝트에 있는 모델과 재질은 가능한 한 재사용한다.

기존 씬이나 게임플레이 스크립트를 임의로 변경하지 말고, 새로운 맵 환경 에셋을 별도로 제작한다.

분석 결과를 먼저 정리한 뒤 각 맵의 예상 크기와 기본 구조를 제안한다.

2. 공통 아트 스타일

다섯 맵은 모두 귀여운 다크 판타지 3D 카툰풍으로 제작한다.

공통 디자인:

둥글고 과장된 형태
쿠키, 초콜릿, 사탕, 아이싱을 활용한 건축물
귀엽지만 어딘가 기괴한 장식
보라색 마법과 저주의 흔적
따뜻한 조명과 차가운 달빛의 대비
선명한 색상과 읽기 쉬운 실루엣
과도한 현실적 디테일보다 게임 화면에서 알아보기 쉬운 형태를 우선

모든 맵은 같은 세계에 존재하는 장소처럼 보이도록 재질과 오브젝트 디자인을 통일한다.

다만 각 맵의 대표 색상, 주요 랜드마크, 지형 구조는 서로 확실히 다르게 제작한다.

3. 공통 맵 설계 규칙

각 맵은 다음의 요소를 갖도록 설계한다.

플레이어가 이동할 수 있는 기본 바닥
넓은 시야가 확보되는 개방 구역
시야가 가려지는 장애물 구역
좁은 통로와 넓은 통로의 조합
서로 연결되는 순환 동선
멀리서도 위치를 파악할 수 있는 랜드마크
배경용 오브젝트와 실제 충돌체를 구분
플레이어가 지나갈 수 있는 공간과 장식 공간을 구분

각 맵의 크기는 기존 캐릭터와 이동 속도, 게임 카메라를 고려해 설정한다.

실제 플레이어가 이동하는 주요 길에는 지나치게 작은 틈이나 불필요한 높낮이를 만들지 않는다.

막다른 길을 무조건 없애지는 말되, 막다른 길마다 술래잡기에 필요한 회피 공간과 탈출 가능성을 고려한다.

각 맵의 오브젝트는 다음 카테고리로 나눈다.

Ground — 기본 지면
Terrain — 언덕과 경사로
MainStructures — 건축물과 대형 구조물
GameplayProps — 실제 게임플레이 공간에 놓이는 오브젝트
Decoration — 장식용 오브젝트
Background — 멀리 보이는 배경
Lighting — 조명과 발광 오브젝트
Effects — 마법, 연기, 안개 등 효과를 위한 배치 기준점

10. 실제 작업 순서

다섯 개의 맵을 한꺼번에 상세 모델링하지 않는다.

다음 순서로 작업한다.

1단계: 전체 맵 블록아웃

각 맵의 바닥과 주요 건축물, 큰 장애물만 배치한다.

이 단계에서는 세부 장식을 만들지 말고, 플레이어가 이동할 수 있는 구조와 시야를 확인한다.

각 맵의 탑 뷰와 게임 카메라 시점에서 블록아웃 렌더 이미지를 생성한다.

2단계: 맵별 디자인 검수

다섯 맵의 블록아웃을 비교하고, 각 맵의 색상과 실루엣, 랜드마크가 충분히 구분되는지 확인한다.

각 맵의 이동 경로와 장애물의 배치를 확인하고, 필요한 경우 구조를 수정한다.

3단계: 주요 오브젝트 제작

맵별로 중요한 랜드마크와 건축물을 모델링한다.

예:

CandyForest: 거대한 사탕 나무
GingerbreadVillage: 과자 시계탑
ChocolateFactory: 초콜릿 탱크
CursedCandyCarnival: 사탕 관람차
HauntedBakery: 마법 오븐
4단계: 환경 에셋 제작

각 맵에 필요한 나무, 버섯, 울타리, 가로등, 가구 등을 모델링한다.

공통 에셋을 우선 제작해 여러 맵에서 재사용한다.

5단계: 배치 및 조명

각 맵에 오브젝트를 배치하고, 맵마다 고유한 조명과 분위기를 적용한다.

게임 카메라 시점에서 랜드마크가 잘 보이는지 확인한다.

6단계: Unity 내보내기

각 맵의 환경 모델과 재질을 정리해 Unity에서 사용할 수 있는 형태로 내보낸다.

맵의 지면, 대형 건축물, 장식물, 충돌체를 분리한다.

실제로 생성한 파일만 완료된 것으로 보고하고, 생성되지 않은 파일은 완료했다고 표시하지 않는다.

11. 최종 결과물

각 맵마다 다음 결과물을 준비한다.

Blender 원본 파일
Unity용 FBX 환경 모델
공통 및 개별 재질
필요한 텍스처
개별 오브젝트 모델
맵별 탑 뷰 렌더 이미지
게임 카메라 시점의 렌더 이미지
맵별 주요 오브젝트 목록
Unity에서 사용할 때 필요한 충돌체와 배치 안내

최종적으로 다섯 개 맵이 하나의 게임 세계관을 공유하면서도, 각 맵의 분위기와 구조가 확실히 구분되도록 제작한다.
