## 3. 애니메이션 설계

과자집 굴뚝 연기와 같은 방식(에디터 빌더가 클립·컨트롤러·프리팹을 생성하고 스스로 검증)으로 만든다. 모든 연출은 **각 클라이언트에서 로컬 재생**한다 — 네트워크 동기화가 필요 없다.

| # | 연출 | 대상 | 방법 | 길이 |
|---|---|---|---|---|
| A1 | **보라 불꽃 활활** | `Fire_Flame_01~13` | 불꽃마다 밑동 기준으로 세로 크기 0.75~1.3배 반복, 가로 살짝 흔들림(±8°), 불꽃마다 시작 시점·주기를 어긋나게 해 동시에 움직이지 않게 | 반복 0.5~0.9초(불꽃별로 다름) |
| A2 | **숯불 일렁임** | `Fire_Coals`(`M_Ember`) | 발광 세기 0.8~1.2배 느린 맥동 + (선택) 솥 밑 Point Light 1개 깜빡임 | 반복 1.6초 |
| A3 | **연기 모락모락** | `Smoke_Puff_01~06` | 세 줄(좌·우·뒤) 각각 굴뚝 연기처럼 아래 칸 → 위 칸으로 이동하며 아래는 크기 0에서 생기고 위는 크기 0으로 사라짐, 살짝 좌우로 흔들림. 이음새 없는 반복 | 반복 2.4초 |
| A4 | **수면 부글부글** | `Liquid_Surface` 블렌드셰이프 `Idle_A`↔`Idle_B`, `Liquid_Bubble_01~03` | 수면이 천천히 출렁이고, 거품이 번갈아 커졌다가 톡 터짐(크기 0) | 반복 1.2초 |
| A5 | **풍덩(한 번)** | `Liquid_Surface`(`Splash_Dip` → `Ripple_*`), `Splash_Crown`, `Splash_Droplet_01~08` | ① 수면이 움푹 꺼짐(0.1초) ② 왕관 물보라가 솟았다 가라앉음 ③ 물방울 8개가 포물선으로 튀어 올랐다 떨어지며 사라짐 ④ 파문이 네 방향으로 퍼지며 잦아듦 | 1.0초 |

- **구조**: 반복 연출(A1~A4)은 기본 레이어에서 항상 재생, 풍덩(A5)은 별도 레이어의 트리거로 재생해 반복 연출을 끊지 않는다.
- **풍덩 트리거**: 새 런타임 스크립트 `CauldronSplash`(`02. Scripts/Environment/`) — 수면 트리거에 들어온 오브젝트를 감지하면 풍덩을 재생(연속 발동 방지 쿨다운 0.5초). 괴물 신청을 하는 `Cauldron.cs`와는 **역할을 분리**한다(연출 ≠ 게임 규칙).
- **네트워크**: 원격 캐릭터도 동기화된 위치로 트리거에 들어오므로 모든 클라이언트에서 같은 풍덩이 보인다. RPC 불필요.
- **도구**: `Assets/Editor/Cauldron/CauldronBuilder.cs`(클립·컨트롤러·프리팹 생성 + 검증 메뉴), `CauldronImportPostprocessor.cs`(재질 리맵, 애니메이션 가져오기 끔).

### 5.1 구현 세부

- **역할 분리**: 대기실 씬의 `Cauldron` 오브젝트는 게임 규칙(`Cauldron.cs` — 괴물 신청, `MonsterRevealController` 연결)만 남기고, 모양·충돌·연출은 새 프리팹을 **자식으로** 둔다. 프리팹이 빌더로 다시 만들어져도 씬의 규칙 연결(인스펙터 참조)이 끊기지 않는다.
- **충돌체**(프리팹): 솥 벽은 원형으로 배치한 **상자 충돌체 16개**(속이 빈 통 — 안으로 들어갈 수 있음), 솥 안 바닥 상자 1개(쿠키가 액체 속에 선다), 장작은 볼록 MeshCollider. 수면 위에 풍덩 감지 트리거.
- **괴물 신청 트리거**(씬 `Cauldron`): 캡슐 메시·캡슐 충돌체를 없애고 **솥 안 수면 높이의 상자 트리거**로 교체 — 쿠키가 솥에 뛰어들어야 신청된다(예전: 캡슐에 닿으면 신청).
- **애니메이션 구조**: 컨트롤러 1개, 레이어 2개. Base = 반복 클립(불꽃·숯불·연기·수면·거품, 길이 2.4초, 모든 주기가 2.4초를 나눠 떨어지게 해 이음새 없음, 풍덩 오브젝트는 크기 0 유지). Splash 레이어(덮어쓰기) = 비어 있다가 트리거 `Splash`로 1초 풍덩 재생.
- **숯불 빛**: 솥 밑에 보라 Point Light 1개(그림자 없음)를 두고 불꽃과 함께 깜빡이게 한다.
- 위치 (0, 0, 0): 과자집 실내 바닥 윗면은 y 0.03이라 솥 발이 3 cm 묻힌다(요청대로 0 유지, 보이는 차이는 거의 없음).
